# Bonjour! — личный тренажёр французского

Небольшой адаптивный сайт для личной практики французского. Он рассчитан на начинающую ученицу, которая хочет увереннее говорить и понимать речь. Одно задание показывается за раз; после урока следующий можно начать сразу — дневных блокировок нет. В профиле можно выбрать обычную длительность занятия: 20, 30 или 60 минут.

## Файлы проекта

- `index.html` — содержание страницы: приветствие, уроки, практические задания, прогресс, профиль и навигация.
- `styles.css` — внешний вид, цвета, карточки, кнопки и правила отображения на узком экране телефона.
- `app.js` — уроки и словарь, аудио, квиз, действия кнопок, расчёт прогресса и сохранение данных.
- `assistant.js` и `assistant.css` — отдельный экран ИИ-собеседника, голосовой ввод/озвучивание и его оформление.
- `api/assistant.js` — серверная функция, которая вызывает бесплатную модель, не раскрывая ключ в браузере.
- `.env.example` — только названия настроек и безопасные примеры; настоящие ключи в него не вставлять.
- `.gitignore` исключает локальные секреты и настройки Vercel из Git.
- `vercel.json` задаёт серверной функции допустимое время ответа.
- `course-plan.html` — подробный план обучения, который открывается как обычная UTF-8 страница сайта.
- `COURSE_PLAN.md` — текстовая исходная версия маршрута A1 → A2.

Сайт не требует npm, сборки или установки библиотек. Для открытия на компьютере достаточно браузера. Чтобы открыть его на телефоне в той же Wi-Fi сети, запусти локальный веб-сервер по инструкции ниже.

## Запуск на компьютере

1. Открой папку проекта `D:\новый проект`.
2. Дважды нажми `index.html` или перетащи его в окно браузера.
3. При первом открытии введи имя. Оно будет использовано в приветствии и разговорной фразе.

Если браузер ограничивает отдельные функции при открытии файла напрямую, запусти сервер локально:

```powershell
cd "D:\новый проект"
py -m http.server 8000
```

Затем открой в браузере компьютера адрес `http://localhost:8000`.

Обычная версия сайта работает как статическая страница. ИИ-собеседнику дополнительно нужны опубликованная серверная функция и собственный ключ модели; GitHub Pages не запускает серверный код.

## Подключить ИИ-помощника

Помощник поддерживает свободный диалог на русском, казахском и французском. Голосовой ввод использует распознавание браузера, а озвучивание — системный голос устройства. Распознавание может быть недоступно в некоторых мобильных браузерах; в таком случае можно использовать диктовку клавиатуры.

Для первого запуска используется бесплатная маршрутизация OpenRouter. На момент подготовки инструкции бесплатные модели ограничены 50 запросами в день и могут быть заняты; OpenRouter отмечает, что лимит/доступность бесплатных моделей может меняться. Сервер просит маршрутизатор требовать нулевое хранение (ZDR) и исключать провайдеров, которые собирают данные (`zdr: true`, `data_collection: "deny"`). Если подходящей бесплатной модели сейчас нет, запрос завершится понятной ошибкой; переключения на платную модель в коде нет. См. [официальные лимиты бесплатных моделей](https://openrouter.ai/collections/free-models/) и [настройки приватной маршрутизации](https://openrouter.ai/docs/guides/get-started/sovereign-ai).

### Опубликовать сервер

1. Создай собственный аккаунт OpenRouter и выпусти API-ключ в разделе [API Keys](https://openrouter.ai/settings/keys). Ключ принадлежит твоему аккаунту; не отправляй его в чат и не вставляй в `app.js`, HTML или GitHub.
2. Создай личный проект на [Vercel](https://vercel.com/), выбери **Add New → Project** и импортируй этот GitHub-репозиторий `qlmiran/-`. Для личного портфолио можно начать с бесплатного Hobby-плана. В репозитории уже есть функция `api/assistant.js` и настройки Vercel.
3. В Vercel открой проект → **Settings → Environment Variables**. Добавь для Production:

   - `OPENROUTER_API_KEY` — вставь свой ключ OpenRouter только в значение переменной Vercel.
   - `BONJOUR_ACCESS_CODE` — создай длинный случайный код, например выполни в PowerShell: `[guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')`. Сохрани его отдельно.
   - `ALLOWED_ORIGINS` — `https://qlmiran.github.io` (это адрес GitHub Pages; без завершающего `/`).

   По желанию можно добавить `https://<имя-проекта>.vercel.app` через запятую, если будешь открывать сам сайт с Vercel. [Vercel хранит переменные среды отдельно от исходного кода и шифрует их](https://vercel.com/docs/environment-variables); только не добавляй в проект людей, которым нельзя видеть эти секреты.
4. После сохранения переменных нажми **Redeploy** в Vercel. Открой появившийся адрес проекта и проверь, что главная страница загружается.
5. На опубликованном GitHub Pages сайте открой вкладку **Помощник**. В поле «Адрес API помощника» введи адрес функции вида `https://<имя-проекта>.vercel.app/api/assistant`, нажми **Сохранить адрес**, затем введи `BONJOUR_ACCESS_CODE` в поле «Код доступа». Этот код действует только пока открыта текущая вкладка и сайт его не сохраняет.
6. Подтверди уведомление о передаче текста и начни разговор. Для проверки отправь отдельные короткие сообщения по-русски, қазақша и français.

GitHub Pages продолжит отдавать сайт. Vercel нужен только для `/api/assistant`. Если позднее поменяешь домен GitHub Pages, обнови `ALLOWED_ORIGINS` в Vercel и сделай новый Deploy.

### Данные и секреты

- В GitHub лежат только исходный код и шаблон `.env.example`, без рабочих ключей. `.gitignore` исключает `.env`, `.env.local` и папку `.vercel`.
- Не вставляй рабочий API-ключ в сайт, настройки профиля, скриншоты, чат или коммиты. Если ключ случайно попал в репозиторий — отзови его в OpenRouter и выпусти новый: удаление коммита само по себе не делает старый ключ безопасным.
- Адрес API — несекретная настройка, сохраняется в браузере. Код доступа не сохраняется, а переписка существует только в памяти текущей вкладки и удаляется при её перезагрузке или кнопкой «Новый разговор».
- При отправке сообщения текст проходит через Vercel к OpenRouter и выбранному бесплатному провайдеру модели. Запрос просит маршрутизировать его только к провайдерам с ZDR и без сбора пользовательских данных, но сообщение всё равно обрабатывает внешний сервис. Не отправляй личные или чувствительные данные. [Политика OpenRouter описывает различия практик провайдеров](https://openrouter.ai/privacy).
- Функция ограничивает размер истории и частоту запросов. Кроме этого, действуют лимиты бесплатного аккаунта OpenRouter; они могут меняться.

## Запуск на телефоне через Wi-Fi

Компьютер и телефон должны быть подключены к одной Wi-Fi сети.

1. Открой PowerShell в папке проекта. В Проводнике можно открыть папку, щёлкнуть адресную строку, написать `powershell` и нажать Enter.
2. Запусти сервер:

   ```powershell
   py -m http.server 8000 --bind 0.0.0.0
   ```

3. Не закрывай окно PowerShell, пока пользуешься сайтом.
4. На компьютере выполни `ipconfig` и найди строку `IPv4-адрес` у адаптера Wi-Fi. Обычно адрес выглядит примерно как `192.168.1.34`.
5. В браузере телефона открой `http://АДРЕС-КОМПЬЮТЕРА:8000`, подставив найденный адрес. Например: `http://192.168.1.34:8000`.
6. Если Windows спросит о сетевом доступе, разреши его для частной сети. Чтобы остановить сервер, вернись в PowerShell и нажми `Ctrl+C`.

Если команда `py` не найдена, установи Python для Windows или попробуй команду `python -m http.server 8000 --bind 0.0.0.0`.

### Про микрофон и озвучивание

В профиле доступны только голоса с именами Амели и Томас, каждый можно прослушать. Список зависит от браузера и системы; если один голос не установлен, сайт не подменяет его другим и подсказывает, что делать. Это системная синтезированная речь, не запись настоящих актёров.

Музыка запускается только по нажатию кнопки ноты. В видимом встроенном YouTube-плеере идут официальные клипы ZAZ, Stromae, Indila и Joe Dassin; после окончания клипа автоматически начинается другая песня. Кнопка «Следующая песня» переключает трек вручную, крестик останавливает и закрывает плеер. Громкость меняется в профиле и снижается во время французской озвучки. Песни не скачиваются и не хранятся в репозитории: сайт использует официальный YouTube IFrame Player API.

Распознавание речи зависит от браузера и его онлайн-сервиса. На телефоне сайт открыт по локальному адресу компьютера вида `http://192.168...`; такой HTTP-адрес не считается защищённым контекстом, поэтому браузер может заблокировать прямой доступ к микрофону. Для прямой записи открой сайт по HTTPS. В упражнении также есть запасной вариант для iPhone: выбрать французскую клавиатуру, нажать поле ответа и микрофон самой клавиатуры, затем сравнить распознанный текст с фразой. Это проверяет слова, а не акцент. Запись себя и последующее прослушивание также доступны на HTTPS. API браузерного распознавания доступен не во всех браузерах и может требовать интернета.

## Как сохраняется прогресс

- Имя, длительность занятия, два выбранных голоса, громкость музыки, пройденные уроки, знакомые слова, серии занятий и шкалы навыков сохраняются в `localStorage` текущего браузера.
- Свои слова с университетских занятий можно добавлять прямо в разделе карточек — они тоже сохраняются и входят в резервную копию.
- Сохранения в браузере телефона и в браузере ноутбука независимы. Облачной синхронизации в этой версии нет.
- Чтобы перенести данные: на исходном устройстве открой «Прогресс» → «Скачать копию». На другом устройстве открой сайт и выбери «Загрузить копию».
- Не очищай данные сайтов в браузере, если хочешь сохранить прогресс на этом устройстве.

## Что происходит в коде

### `index.html` — структура

1. В `<head>` задаются русский язык страницы, масштаб для телефона, цвет браузерной панели, название вкладки и подключение CSS/JavaScript.
2. `.topbar` содержит название сайта, серию занятий и кнопку профиля.
3. `#view-home` — приветствие, дневной план, мотивационная цитата, сводка прогресса и интересы ученицы.
4. `#view-learn` — шесть вводных тем, переход к подробному плану, прямые встроенные ролики, рекомендации фильмов, фото-подборка и меняющиеся мемы.
5. `#view-practice` — последовательные экраны с аудиодиалогом Амели и Томаса, миссией, фото, встроенным видео, GIF-мемом, сценой с выбором реплики, диктовкой, квизом и карточками слов. Переход с первого задания блокируется до окончания диалога и подтверждения.
6. `#view-progress` — навыки, недельная цель, примерный темп и импорт/экспорт сохранения.
7. `.bottom-nav` переключает пять экранов и остаётся закреплённой внизу телефона.
8. Элементы `<dialog>` показывают профиль, словарь и содержание урока поверх текущего экрана.

### `styles.css` — внешний вид

- В начале `:root` находятся основные цвета, шрифты и тени. Чтобы поменять общую палитру, начни с переменных `--orange`, `--yellow`, `--pink`, `--purple` и `--paper`.
- Основные правила задают карточки, кнопки, панели, прогресс-бары, диалоговые окна и навигацию.
- `@media (max-width: 850px)` перестраивает широкую раскладку для планшетов.
- `@media (max-width: 620px)` делает интерфейс компактным и одноколоночным для телефона.
- `prefers-reduced-motion` уменьшает анимацию, если пользователь включил системное ограничение движения.

### `app.js` — данные и поведение

1. `lessons`, `lessonActivities` и `dialogue` — темы, диалоги, фразы, квизы и карточки. `practiceVideos`, `practicePhotos` и `practiceMemes` задают материалы к каждому уроку, а `dailyQuotes` хранит цитаты и мотивационные фразы. Содержание шести вводных уроков связано с выбранной темой.
2. `initialState` описывает пустой профиль. `loadState()` читает сохранение браузера, `saveState()` записывает изменения и обновляет интерфейс.
3. `recordLessonActivity()`, `calculateStreak()` и `weeklyLessonCount()` ведут календарь занятий, серию и недельную цель.
4. `renderLessons()`, `renderPracticeContent()`, `renderDialogue()` и `renderSkills()` создают карточки и подставляют тематические упражнения.
5. `renderPracticeStep()` показывает одну активность, обновляет индикатор шага и блокирует переход, пока не пройден первый диалог. `movePracticeStep()` повторно проверяет условие перед переходом.
6. `frenchVoices()` собирает доступные французские голоса, а `renderSpeakerSettings()` заполняет два списка в профиле. `speakFrench()` использует голос роли Амели или Томаса и приглушает фон во время речи.
7. `startBackgroundMusic()` открывает видимый YouTube-плеер с французской подборкой после нажатия пользователя. `nextMusicTrack()` переключает песню после окончания клипа или по кнопке, `toggleBackgroundMusic()` включает и останавливает подборку, а `duckBackgroundMusic()` приглушает её во время реплик.
8. `allWords()` объединяет встроенные карточки и личные слова. Форма «Добавить слово с занятия» сохраняет новые французские слова и перевод в профиле.
9. `openLesson()` показывает описание темы, а кнопка «Начать урок» запускает последовательность заданий. Завершение маршрута сохраняет тему в пройденных.
10. `markPractice()` засчитывает аудирование, построение фраз или разговорную практику и повышает соответствующий навык.
11. `answerQuiz()` проверяет ответ, показывает подсказку и позволяет попробовать снова после ошибки.
12. `startSpeechRecognition()` использует встроенный интерфейс распознавания речи браузера, если он доступен; `recordPracticeAudio()` даёт запасной способ записать и переслушать себя.
13. `exportProgress()` скачивает JSON-файл, а `importProgress()` переносит сохранение на другое устройство.
14. `renderDailyQuote()` выбирает случайную цитату без повтора подряд. `openVideoPlayer()` и `openPracticeVideo()` собирают прямой адрес встроенного видео и запускают его по нажатию.
15. `bindEvents()` связывает кнопки со своими действиями. `init()` рисует интерфейс и при первом запуске предлагает заполнить имя.

### `assistant.js` и `assistant.css` — ИИ-собеседник

- `assistant.js` обрабатывает сообщения, голосовую диктовку, озвучивание, быстрые темы для начала и ошибки соединения.
- Модель получает системную инструкцию отвечать на языке пользователя и может помогать с французским A1–A2, не превращая любой вопрос в урок.
- Текст чата хранится только в массиве JavaScript текущей вкладки. В сеть уходит до 12 последних реплик. Перезагрузка или «Новый разговор» очищает переписку.
- Адрес API можно сохранить в `localStorage`, чтобы не вводить повторно. Код доступа остаётся в поле страницы и отправляется только серверу; он не записывается в `localStorage`.
- Голос микрофона выбирается отдельно для русского, казахского и французского. Ответы можно озвучить, используя системный голос или автоматический выбор языка по тексту.
- `assistant.css` задаёт чат, пузырьки сообщений, блок подключения и адаптацию для телефона.

### `api/assistant.js` — вызов модели

- Функция принимает только текстовые сообщения `user` и `assistant`, ограничивает размер запроса и проверяет код доступа.
- Ключ `OPENROUTER_API_KEY` читается из переменной среды хостинга и никогда не передаётся браузеру.
- В запросе всегда используется `openrouter/free`; код не умеет переключаться на платную модель. Также передаются настройки `zdr: true` и `data_collection: "deny"`.
- `ALLOWED_ORIGINS` ограничивает адреса сайтов, с которых браузер может обращаться к функции. Лимит частоты запросов уменьшает случайное злоупотребление.
- Ответы и ошибки отправляются без хранения текста переписки в функции. Внешний AI-провайдер всё равно обрабатывает сообщение для ответа; детали подключения описаны в разделе выше.

## Где менять содержание

Подробная последовательность тем, формат занятий и контрольные точки показаны на странице `course-plan.html`; текстовая версия сохранена в `COURSE_PLAN.md`. Видео из серии Institut français и трейлер «Le Petit Nicolas» открываются прямо во встроенном YouTube-плеере с автозапуском по нажатию. В первом задании кнопка перехода остаётся закрытой, пока весь диалог не прозвучит и ученица не подтвердит выполнение; при отсутствии системной озвучки можно прочитать реплики и подтвердить это. Цитаты случайно выбираются из расширенного списка без повтора подряд. В упражнениях есть короткие видео, GIPHY-реакции и тематические фотографии Unsplash. Процент на сайте показывает, сколько вводных карточек пройдено. Он не измеряет уровень CEFR и не заменяет проверку разговора и аудирования.

ИИ-помощник подключается через `assistant.js` и серверную функцию `api/assistant.js`. Секретный API-ключ хранится только в переменных среды Vercel. Порядок публикации и подключения описан выше.

- **Добавить урок:** добавь новый объект в массив `lessons` в `app.js`. Укажи уникальный `id`, название, короткое описание, пример французской фразы и перевод.
- **Добавить карточку по ходу занятий:** в разделе «Практика» нажми «Добавить слово с занятия» и введи французский вариант и перевод. Для постоянных встроенных карточек добавь объект `{ fr: "Французский текст", ru: "Перевод", say: "Текст для аудио" }` в массив `words`.
- **Добавить реплику диалога:** добавь объект `{ who: "C", fr: "Фраза", ru: "Перевод" }` в массив `dialogue`. Для реплики ученицы используй `who: "T"`.
- **Поменять частоту челленджа:** сейчас цель равна четырём учебным дням в неделю. Ищи число `4` в `index.html` и функции `updateProgressDisplays()` в `app.js`.
